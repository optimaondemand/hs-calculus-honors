📖 TODAY'S FOCUS
The average of a few numbers is easy. What is the average of infinitely many?
You have averaged lists of numbers since elementary school: add them up, divide by how many. But a temperature, a velocity, or a rate of flow takes infinitely many values over an interval, and no list captures them. The integral does. It adds up the values of a function continuously, and dividing by the length of the interval gives the average. The idea quickly pays off in two ways. It supplies a theorem with a familiar shape, because the average value is always attained by the function somewhere. And it explains an important distinction in motion: the average of a velocity (which can cancel) is not the average of a speed (which cannot).
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to define and compute the average value \(\dfrac{1}{b-a}\int_a^b f(x)\,dx\) of a continuous function, and explain it as the height of a rectangle with the same area as the region under the curve.
2
I will be able to state and prove the Mean Value Theorem for Integrals from the Extreme Value Theorem and the Intermediate Value Theorem, and find the value of \(c\) it guarantees.
3
I will be able to interpret the average value of a rate as net change divided by time, and tell average velocity from average speed.

📚 PART 1 · THE AVERAGE OF INFINITELY MANY VALUES
⚡ QUICK CHECK-IN
The temperature in a greenhouse is recorded as a smooth function of time over one day. Someone asks for “the average temperature of the day.” You could average the 24 hourly readings, but readings every minute would give a slightly different answer. What would make the best single definition of the average?

For \(n\) numbers you add them and divide by \(n\). For a continuous function there are infinitely many values to average, so we need to make the same move that built the integral in Lesson 13.02: sample at \(n\) evenly spaced points, average the samples, and let \(n\) grow.

Divide \([a,b]\) into \(n\) pieces of width \(\Delta x=\dfrac{b-a}{n}\) and sample \(f\) at a point \(x_i\) in each piece. The average of the \(n\) samples is

\[ \frac{f(x_1)+f(x_2)+\cdots+f(x_n)}{n}=\frac{1}{b-a}\Bigl[f(x_1)\Delta x+f(x_2)\Delta x+\cdots+f(x_n)\Delta x\Bigr], \]

because \(\tfrac1n=\dfrac{\Delta x}{b-a}\). The bracket is a Riemann sum (Lesson 13.02). As \(n\to\infty\) it approaches \(\int_a^b f(x)\,dx\), so the average approaches that integral divided by \(b-a\).

Average Value of a Function
If \(f\) is continuous on \([a,b]\), its average value on \([a,b]\) is \[ f_{\text{avg}}=\frac{1}{b-a}\int_a^b f(x)\,dx. \]

Example 1. Find the average value of \(f(x)=x^2\) on \([0,3]\). \(\displaystyle\int_0^3x^2\,dx=\left[\tfrac{x^3}{3}\right]_0^3=9\), so \(f_{\text{avg}}=\tfrac13\cdot9=3\). Notice that this is less than the largest value of the function, \(f(3)=9\), and more than the smallest, \(f(0)=0\), as an average must be.

Example 2. Find the average value of \(f(x)=\sin x\) on \([0,\pi]\). \(\displaystyle\int_0^{\pi}\sin x\,dx=\left[-\cos x\right]_0^{\pi}=2\), so \(f_{\text{avg}}=\dfrac{2}{\pi}\approx0.637\). The sine hump has height \(1\) at its peak, and its average height over the arch is about \(0.64\).

A rectangle with the same area

Rewrite the definition as \(f_{\text{avg}}\cdot(b-a)=\int_a^b f(x)\,dx\). The right side is the area under the curve. The left side is the area of a rectangle with width \(b-a\) and height \(f_{\text{avg}}\). So the average value is the height of the rectangle that has the same area as the region under the curve: it levels the hills into the valleys.

📚 PART 2 · THE MEAN VALUE THEOREM FOR INTEGRALS

In the figure, the curve \(y=x^2\) actually reaches the average height \(3\) at a point: \(c^2=3\) gives \(c=\sqrt3\approx1.73\), which is inside \([0,3]\). Does a continuous function always attain its own average value somewhere? Yes, and the reason is a pleasing meeting of two earlier theorems.

The Mean Value Theorem for Integrals
If \(f\) is continuous on \([a,b]\), there is at least one number \(c\) in \([a,b]\) with \[ f(c)=\frac{1}{b-a}\int_a^b f(x)\,dx. \]

Proof

Because \(f\) is continuous on the closed interval, the Extreme Value Theorem (Lesson 3.04) gives an absolute minimum value \(m\) and an absolute maximum value \(M\) on \([a,b]\), so \(m\le f(x)\le M\) for every \(x\). Integrating the inequality (the comparison property from Lesson 13.03) gives \(m(b-a)\le\int_a^b f\,dx\le M(b-a)\), and dividing by \(b-a\),

\[ m\le f_{\text{avg}}\le M. \]

So the average value lies between the minimum and maximum values of \(f\). A continuous function takes every value between its minimum and its maximum, by the Intermediate Value Theorem (Lesson 3.03). Therefore \(f\) takes the value \(f_{\text{avg}}\) at some \(c\) in \([a,b]\). \(\blacksquare\)

Convince a classmate: which two earlier theorems did the proof use, and what did each one supply? (Hint: one guaranteed that a minimum and a maximum exist; the other guaranteed that nothing between them is skipped.)

The name is deliberate. The Mean Value Theorem of Lesson 8.03 says that some tangent slope equals the average rate of change. This theorem says that some function value equals the average value. They are the same theorem seen from two sides: apply the first to an antiderivative \(F\) of \(f\), and \(F(b)-F(a)=F^{\prime}(c)\,(b-a)=f(c)(b-a)\). The Fundamental Theorem turns that left side into \(\int_a^b f\,dx\), and the equation says exactly what we proved above.

Example 3. Find the average value of \(f(x)=3x^2-2x\) on \([1,3]\), and find a point \(c\) where it is attained. \(\displaystyle\int_1^3(3x^2-2x)\,dx=\left[x^3-x^2\right]_1^3=(27-9)-(1-1)=18\), so \(f_{\text{avg}}=\tfrac{18}{2}=9\). Now solve \(3c^2-2c=9\), that is \(3c^2-2c-9=0\), giving \(c=\dfrac{1\pm2\sqrt7}{3}\). The minus root is negative, so it is outside \([1,3]\). The plus root is \(\dfrac{1+2\sqrt7}{3}\approx2.10\), which lies in \([1,3]\). As with Rolle and the MVT, solving the equation can return extra solutions that you must discard because they lie outside the interval.

⚠️ COMMON MISTAKE
The average value of a function is not the average of its values at the two endpoints. For \(f(x)=x^2\) on \([0,3]\), the endpoints give \(\tfrac{0+9}{2}=4.5\), but the true average value is \(3\). The curve spends more of its time low than high, and only the integral takes that into account. (For a straight line the two do agree, and that is the only case where the shortcut works.)
▶  Try it in your notebook first: find the average value of \(f(x)=e^x\) on \([0,2]\) as an exact expression. Then estimate it as a decimal, and check that your answer lies between \(f(0)\) and \(f(2)\). Then reveal the check.
\(\displaystyle\int_0^2e^x\,dx=e^2-1\), so \(f_{\text{avg}}=\dfrac{e^2-1}{2}\approx3.19\). The smallest value of \(e^x\) on the interval is \(e^0=1\) and the largest is \(e^2\approx7.39\), and \(3.19\) lies between them, as it must. Where is it attained? \(e^c=\tfrac{e^2-1}{2}\) gives \(c=\ln\!\left(\tfrac{e^2-1}{2}\right)\approx1.16\), which is in \([0,2]\).
📚 PART 3 · AVERAGE VALUE OF A RATE

Average value matters most when the function is a rate. The Net Change Theorem (Lesson 14.03) says that the integral of a rate is the total change in the quantity. Dividing by the length of time gives the average rate, and for a velocity that is the average velocity.

\[ v_{\text{avg}}=\frac{1}{b-a}\int_a^b v(t)\,dt=\frac{s(b)-s(a)}{b-a}. \]

Notice that this is exactly the quotient of the Mean Value Theorem for derivatives: average velocity is displacement over time. The Mean Value Theorem for integrals now says the velocity actually equals that average at some instant, which is the toll-booth argument from Lesson 8.04 once more.

Example 4 (velocity versus speed). A particle moves along a line with velocity \(v(t)=t^2-4t+3=(t-1)(t-3)\) for \(0\le t\le4\). Its velocity is positive on \([0,1)\), negative on \((1,3)\), and positive again on \((3,4]\). Compute each piece:

\[ \int_0^1v\,dt=\tfrac43,\qquad \int_1^3v\,dt=-\tfrac43,\qquad \int_3^4v\,dt=\tfrac43. \]

The average velocity uses the signed total: \(\dfrac14\left(\tfrac43-\tfrac43+\tfrac43\right)=\dfrac14\cdot\dfrac43=\dfrac13\). It is the net displacement divided by time, so backward motion subtracts. The average speed uses the absolute value, \(\dfrac14\int_0^4|v|\,dt=\dfrac14\left(\tfrac43+\tfrac43+\tfrac43\right)=1\), total distance divided by time, so all motion counts. The two differ because the particle turned around, which is why the sign chart of \(v\) from Lesson 12.03 decides everything.

Example 5 (average from data). A rover’s speed (in meters per second) is measured every 2 seconds: \(0,\;10,\;14,\;12,\;4\) at \(t=0,2,4,6,8\). Estimate the integral with the Trapezoidal Rule (Lesson 13.04): \(\dfrac22\bigl[0+2(10)+2(14)+2(12)+4\bigr]=76\) meters. The average speed over the 8 seconds is about \(\dfrac{76}{8}=9.5\) m/s.

💡 DID YOU KNOW?
Engineers do not report household voltage as a peak. The “120 volts” from a wall socket is a root-mean-square value, the square root of the average value of the squared voltage over one cycle, and it is not the 170-volt peak of the wave. An integral divided by a length shows up wherever a changing quantity needs a single honest summary.

💪 THE ONE IDEA TO CARRY FORWARD

The average value of a continuous function on \([a,b]\) is \(\dfrac{1}{b-a}\int_a^b f(x)\,dx\), the height of the rectangle with the same area as the region under the curve. A continuous function attains that average at some point, because the Extreme Value Theorem puts it between the minimum and maximum and the Intermediate Value Theorem fills in every value between. For a velocity, the average is net displacement over time, and average speed, which uses \(|v|\), is total distance over time. Lesson 16.03 keeps the same integral and changes what it adds: instead of strips of height, it adds up slices of known area, to measure the volume of a solid.

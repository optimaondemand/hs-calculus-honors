📖 TODAY'S FOCUS
Every rule so far differentiates one function. Today's rule differentiates a function built out of two.
\((3x+1)^5\) is not a polynomial you would want to expand by hand, and none of Module 5's five rules, alone, differentiates it directly. But look closer: it is really two simple functions, stacked. Something happens to \(x\) first (multiply by 3, add 1), and then something happens to that result (raise it to the fifth power). Nearly every function you will meet for the rest of this course is built this way, one function feeding into another, and the rule that differentiates a stack like this is arguably the single most important rule you will learn all year: the Chain Rule.
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to identify the outer and inner functions in a composite function.
2
I will be able to state the Chain Rule and justify it with a difference-quotient argument, and name honestly the one gap that argument leaves open.
3
I will be able to apply the Chain Rule, including the General Power Rule, to differentiate composite algebraic functions.

📚 PART 1 · OUTER FUNCTIONS AND INNER FUNCTIONS
⚡ QUICK CHECK-IN
For \(y = (3x+1)^5\), one function happens first (the "inside") and a second function happens to that result (the "outside"). Which is which here? Take a guess.

A composite function \((f\circ g)(x) = f(g(x))\) applies \(g\) first and \(f\) second. Call \(g\) the inner function and \(f\) the outer function. For \(y=(3x+1)^5\), let \(u = g(x) = 3x+1\) be the inner function and \(y = f(u) = u^5\) be the outer function; then \(y = f(g(x))\). Learning to see this decomposition on sight, before differentiating anything, is most of the work of using the Chain Rule well.

More decompositions

\(y = \sqrt{x^2+4}\): inner \(u = x^2+4\), outer \(y = \sqrt{u} = u^{1/2}\).

\(y = \dfrac{1}{(x^2+1)^3}\): inner \(u = x^2+1\), outer \(y = u^{-3}\).

📚 PART 2 · STATING AND JUSTIFYING THE CHAIN RULE

If \(u=g(x)\) is differentiable at \(x\) and \(y=f(u)\) is differentiable at that value of \(u\), then the composite \(y=f(g(x))\) is differentiable, and

\[ \boxed{\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}} \qquad\text{equivalently}\qquad (f\circ g)'(x) = f'(g(x))\cdot g'(x) \]

Here is where the Leibniz notation earns its keep: the rule reads as if \(du\) simply cancels, and that is exactly the intuition behind the following justification. Write the difference quotient for \(y\) with respect to \(x\), and, wherever \(\Delta u \ne 0\), multiply by \(\frac{\Delta u}{\Delta u}\):

\[ \frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u}\cdot\frac{\Delta u}{\Delta x} \]

As \(\Delta x \to 0\), the factor \(\frac{\Delta u}{\Delta x} \to \frac{du}{dx} = g'(x)\) by definition. And because \(g\) is differentiable at \(x\), Lesson 4.04 already proved it is continuous there, so \(\Delta u \to 0\) as \(\Delta x \to 0\) as well. That sends the first factor to \(\frac{\Delta y}{\Delta u} \to \frac{dy}{du} = f'(u)\). Multiplying the two limits gives \(\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}\), as claimed.

🧩 WORTH KNOWING · THE HONEST GAP
This argument has a real gap, and it is worth naming rather than smoothing over: multiplying by \(\frac{\Delta u}{\Delta u}\) is only legal where \(\Delta u \ne 0\). For most functions \(g\) that never becomes an issue, but a differentiable function can have \(\Delta u = 0\) for values of \(\Delta x\) arbitrarily close to 0 (a function that oscillates while flattening toward its tangent line can do this). The Chain Rule remains true even then; the full, fully rigorous proof patches the gap with an auxiliary function built specifically to avoid dividing by \(\Delta u\) at all. That proof is real analysis, beyond this course, and it is exactly the kind of edge Lesson 5.04 asked you to notice rather than paper over: this proof covers the ordinary case honestly and says so where it stops.
📚 PART 3 · THE GENERAL POWER RULE AND WORKED EXAMPLES

The single most common outer function is a power, \(y=u^n\), so it is worth its own name. Since \(\frac{dy}{du} = nu^{n-1}\) by the Power Rule, the Chain Rule gives the General Power Rule:

\[ \boxed{\dfrac{d}{dx}\left[u^n\right] = n\,u^{n-1}\cdot\dfrac{du}{dx}} \]

Worked example 1

Differentiate \(y=(3x+1)^5\). Here \(u=3x+1\), \(n=5\), and \(\frac{du}{dx}=3\):

\[ \frac{dy}{dx} = 5(3x+1)^4\cdot 3 = 15(3x+1)^4 \]

Worked example 2

Differentiate \(y=\sqrt{x^2+4}\). Rewrite as \(y=(x^2+4)^{1/2}\), with \(u=x^2+4\), \(n=\tfrac12\), \(\frac{du}{dx}=2x\):

\[ \frac{dy}{dx} = \tfrac12(x^2+4)^{-1/2}\cdot 2x = \frac{x}{\sqrt{x^2+4}} \]

⚠️ COMMON MISTAKE
Forgetting to multiply by \(\frac{du}{dx}\) is the single most common Chain Rule error in this course. \(\dfrac{d}{dx}[(3x+1)^5]\) is not \(5(3x+1)^4\); it is \(5(3x+1)^4\cdot 3\). The outer derivative alone is only half the rule — always multiply by the derivative of what is inside.

💪 THE ONE IDEA TO CARRY FORWARD

Whenever a function is built by feeding one function into another, its derivative is the outer derivative, evaluated at the inner function, multiplied by the inner derivative: \(\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}\). Almost every function from here to the end of the year, algebraic, trigonometric, exponential, or logarithmic, will be differentiated by finding the layers and applying exactly this rule to each one.

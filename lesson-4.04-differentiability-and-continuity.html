📚 PART 1 · FOUR WAYS A DERIVATIVE CAN FAIL

The limit \( \lim_{h\to 0} \dfrac{f(a+h)-f(a)}{h} \) can fail to exist at \(a\) for a few recognizable reasons:

Corner
The one-sided slopes at the point are different finite numbers, like \(f(x) = |x|\) at \(x=0\).
Cusp
The one-sided slopes both march off to infinity, but with opposite signs, like \(f(x) = x^{2/3}\) at \(x=0\).
Vertical tangent
The one-sided slopes both go to the same infinity, like \(f(x)=x^{1/3}\) at \(x=0\); the tangent line is vertical, so its slope is undefined.
Discontinuity
A jump, hole, or infinite break; you already know from Module 3 that a broken graph gives no tangent line at all.

The first three keep the function continuous; only the sharpness or steepness of the graph blocks the derivative. The fourth blocks it because the function itself already fails to be continuous.

📚 PART 2 · A CONTINUOUS FUNCTION THAT IS NOT DIFFERENTIABLE

Worked example: \(f(x) = |x|\) at \(x = 0\)

\(f(x) = |x|\) is continuous everywhere, including at \(x = 0\): there is no hole, no jump, and \(f(0) = 0\) matches the limit from both sides. Now test differentiability with one-sided difference quotients.

\[ \lim_{h \to 0^+} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1 \] \[ \lim_{h \to 0^-} \frac{|0+h| - |0|}{h} = \lim_{h \to 0^-} \frac{-h}{h} = -1 \]

The one-sided limits disagree, 1 from the right and \(-1\) from the left, so the two-sided limit that defines \(f'(0)\) does not exist. \(f(x) = |x|\) is continuous at \(x = 0\) but not differentiable there. The graph has a corner: it approaches from two different directions with two different slopes.

💡 WHY DIFFERENTIABLE IMPLIES CONTINUOUS
If \(f'(a)\) exists, then for \(x\) near \(a\), \(f(x) - f(a) = \left[\dfrac{f(x)-f(a)}{x-a}\right](x-a)\). As \(x \to a\), the bracket approaches the finite number \(f'(a)\) and the factor \((x-a)\) approaches 0, so their product approaches \(f'(a)\cdot 0 = 0\) by the product law for limits. That means \(f(x) \to f(a)\), which is exactly what continuity at \(a\) requires. The argument only runs in one direction: nothing here says the reverse must hold, which is exactly the gap that \(f(x) = |x|\) falls into.
💡 DID YOU KNOW?
In 1872 the German mathematician Karl Weierstrass presented a function that is continuous at every single point yet differentiable at none of them, an infinitely jagged curve with no smooth stretch anywhere. Many mathematicians of the time found the result almost impossible to accept, since intuition suggested that a continuous curve should be smooth somewhere. It stands as a permanent warning: continuity guarantees far less than it seems to.

💪 THE ONE IDEA TO CARRY FORWARD

Differentiable always means continuous, but continuous never guarantees differentiable. A corner, a cusp, a vertical tangent, or a break in the graph can each stop a derivative from existing even where the function itself behaves well. You built the derivative from the limit definition this module; next quarter you will learn faster rules for computing it, all of which rest on exactly the reasoning you practiced here.

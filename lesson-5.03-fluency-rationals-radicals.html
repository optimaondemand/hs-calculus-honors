📖 TODAY'S FOCUS
The Power Rule was proved for positive whole-number exponents. Does it survive when the exponent is negative, or a fraction?
Lesson 5.01 proved \(\dfrac{d}{dx}\big[x^n\big] = n\,x^{n-1}\) only for positive integers \(n\), using the Binomial Theorem, which only makes sense for whole-number powers. Today you check whether the same formula holds when \(n\) is negative, and you check it against evidence you already have for fractional \(n\). By the end, you will differentiate any algebraic function, polynomial, rational, or radical, and know exactly how much of the general rule you have actually proved versus verified.

📚 PART 1 · NEGATIVE EXPONENTS, PROVED FROM THE QUOTIENT RULE
⚡ QUICK CHECK-IN
The Power Rule says \(\dfrac{d}{dx}[x^n] = n x^{n-1}\). If that pattern simply continues for \(n = -2\), what would you guess \(\dfrac{d}{dx}\big[x^{-2}\big]\) is? (No wrong answer. Just apply the pattern and see what it predicts.)

The Binomial Theorem proof from Lesson 5.01 only makes sense when \(n\) is a positive integer; \((x+h)^{-2}\) is not a binomial expansion. But the Quotient Rule, proved last lesson with no restriction on the sign of an exponent, reaches negative powers directly. For a positive integer \(n\), write \(x^{-n} = \dfrac{1}{x^n}\) and apply the Quotient Rule with \(u=1\) (so \(u'=0\)) and \(v = x^n\) (so \(v' = n x^{n-1}\), already proved):

\[ \frac{d}{dx}\left[x^{-n}\right] = \frac{d}{dx}\left[\frac{1}{x^n}\right] = \frac{(0)(x^n) - (1)(n x^{n-1})}{(x^n)^2} = \frac{-n\,x^{n-1}}{x^{2n}} = -n\,x^{n-1-2n} = -n\,x^{-n-1} \]

Now let \(m = -n\), so the exponent on the left is \(m\). The result reads \(-n\,x^{-n-1} = m\,x^{m-1}\), exactly the Power Rule's formula, with the negative integer \(m\) in place of \(n\). So the Power Rule holds for every negative integer exponent too, fully proved, not just guessed: \(\dfrac{d}{dx}\big[x^{-2}\big] = -2x^{-3}\), matching the check-in prediction above.

💡 DID YOU KNOW?
Negative and fractional exponents were themselves once controversial notation. Nicolas Chuquet and Nicolas Oresme experimented with fractional powers as early as the 14th and 15th centuries, but it was John Wallis, in 1656, who first wrote negative and fractional exponents in essentially the form you use today, and argued they should obey the same laws as whole-number exponents. You just proved his instinct correct for the derivative rule, four centuries later.
📚 PART 2 · RATIONAL EXPONENTS: WHAT IS PROVED, WHAT IS VERIFIED

Does \(\dfrac{d}{dx}\big[x^n\big] = n\,x^{n-1}\) also hold when \(n\) is a fraction, like \(\tfrac12\) or \(\tfrac13\)? Neither the Binomial Theorem nor the Quotient Rule proof from Part 1 covers this case directly. But you already have one piece of hard evidence: in Lesson 4.03, working straight from the limit definition and rationalizing the numerator, you found

\[ \frac{d}{dx}\left[\sqrt{x}\,\right] = \frac{1}{2\sqrt{x}} \]

Rewrite \(\sqrt{x} = x^{1/2}\). The Power Rule's formula would predict \(\dfrac{d}{dx}\big[x^{1/2}\big] = \tfrac12 x^{-1/2} = \dfrac{1}{2x^{1/2}} = \dfrac{1}{2\sqrt{x}}\). That is exactly the answer the limit definition produced. The pattern holds here too, confirmed by direct computation rather than by a general argument.

🧩 WORTH KNOWING · AN HONEST GAP, NAMED OUT LOUD
Here is exactly where this course stands: the Power Rule is fully proved for every integer exponent, positive (Lesson 5.01) and negative (Part 1 above), and it has been verified, not yet proved in general, for the one fractional exponent you have checked by hand. A single confirmed case is evidence, not a proof; the pattern could in principle fail somewhere you have not checked. Module 7 will close this gap completely with a technique called implicit differentiation, which proves the Power Rule for every rational exponent at once. Until then, this course adopts the general rule, \(\dfrac{d}{dx}\big[x^n\big] = n\,x^{n-1}\) for any rational \(n\), on the strength of the evidence so far, and says so plainly rather than quietly treating "verified once" as "proved."

With that adopted, every root becomes differentiable by first rewriting it as a fractional power. For \(\sqrt[3]{x} = x^{1/3}\):

\[ \frac{d}{dx}\left[\sqrt[3]{x}\,\right] = \frac{d}{dx}\left[x^{1/3}\right] = \frac13 x^{-2/3} = \frac{1}{3x^{2/3}} = \frac{1}{3\sqrt[3]{x^2}} \]

📚 PART 3 · BUILDING FLUENCY ACROSS THREE FORMS

The same function can appear in radical form, rational-exponent form, or as the input to a rule you already know. Reading fluently across all three is what today's fluency is really about.

Radical form Rational-exponent form Derivative
\(\sqrt{x}\)\(x^{1/2}\)\(\tfrac12 x^{-1/2} = \dfrac{1}{2\sqrt{x}}\)
\(\sqrt[3]{x}\)\(x^{1/3}\)\(\tfrac13 x^{-2/3} = \dfrac{1}{3\sqrt[3]{x^2}}\)
\(\dfrac{1}{x^3}\)\(x^{-3}\)\(-3x^{-4} = -\dfrac{3}{x^4}\)
\(\sqrt{x^3}\)\(x^{3/2}\)\(\tfrac32 x^{1/2} = \dfrac32\sqrt{x}\)

Worked example: a mixed function

Differentiate \(f(x) = 4x^{-3} + 2\sqrt{x} - 7\). Rewrite \(\sqrt{x} = x^{1/2}\), then apply the Power Rule term by term:

\[ f'(x) = 4(-3)x^{-4} + 2\left(\tfrac12\right)x^{-1/2} - 0 = -12x^{-4} + x^{-1/2} = -\frac{12}{x^4} + \frac{1}{\sqrt{x}} \]

▶  Try it in your notebook first: differentiate \(g(x) = \dfrac{3}{x^2} - \sqrt[3]{x} + 5x\). Then reveal the check.
Rewrite \(\dfrac{3}{x^2} = 3x^{-2}\) and \(\sqrt[3]{x} = x^{1/3}\). Then \(g'(x) = 3(-2)x^{-3} - \tfrac13 x^{-2/3} + 5 = -6x^{-3} - \tfrac13 x^{-2/3} + 5 = -\dfrac{6}{x^3} - \dfrac{1}{3\sqrt[3]{x^2}} + 5\).

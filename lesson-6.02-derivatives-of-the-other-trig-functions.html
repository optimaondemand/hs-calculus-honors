📖 TODAY'S FOCUS
You already have every tool this lesson needs; today is about combining them.
Four more trigonometric functions remain: tangent, cotangent, secant, and cosecant. None of them needs a new proof technique. Each is a ratio built entirely from \(\sin x\) and \(\cos x\), the two functions Lesson 6.01 differentiated from scratch, so the Quotient Rule from Lesson 5.02 finishes the job in a few lines each. This is what it feels like when a toolkit is genuinely complete: a whole new family of results falls out of tools you already trust, with no new proof machinery required.
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to derive \(\frac{d}{dx}[\tan x] = \sec^2 x\) and \(\frac{d}{dx}[\cot x] = -\csc^2 x\) using the Quotient Rule and the Pythagorean identity.
2
I will be able to derive \(\frac{d}{dx}[\sec x] = \sec x\tan x\) and \(\frac{d}{dx}[\csc x] = -\csc x\cot x\) the same way.
3
I will be able to differentiate fluently using all six trigonometric derivatives together.
📋 WHAT YOU NEED FOR THIS LESSON
▶
Your math notebook and a pencil, and today's rules from Lesson 6.01: \(\frac{d}{dx}[\sin x]=\cos x\) and \(\frac{d}{dx}[\cos x]=-\sin x\).
▶
The Quotient Rule from Lesson 5.02, the Pythagorean identity \(\sin^2 x + \cos^2 x = 1\), and the ratio identities \(\tan x = \frac{\sin x}{\cos x}\), \(\cot x = \frac{\cos x}{\sin x}\), \(\sec x = \frac{1}{\cos x}\), \(\csc x = \frac{1}{\sin x}\).
📚 PART 1 · TANGENT AND COTANGENT
⚡ QUICK CHECK-IN
\(\tan x = \dfrac{\sin x}{\cos x}\) is a ratio of two functions you can already differentiate. Which Module 5 rule is built exactly for differentiating a ratio? Name it before reading on.

Write \(\tan x = \dfrac{\sin x}{\cos x}\) and apply the Quotient Rule, \(\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}\), with \(u=\sin x\) and \(v=\cos x\):

\[ \frac{d}{dx}[\tan x] = \frac{(\cos x)(\cos x) - (\sin x)(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} \]

The numerator is exactly the Pythagorean identity, \(\cos^2 x + \sin^2 x = 1\), so the whole expression collapses to \(\frac{1}{\cos^2 x}\), which is \(\sec^2 x\) by definition:

\[ \boxed{\dfrac{d}{dx}[\tan x] = \sec^2 x} \]

Cotangent follows the identical pattern with \(\cot x = \dfrac{\cos x}{\sin x}\), \(u=\cos x\), \(v=\sin x\):

\[ \frac{d}{dx}[\cot x] = \frac{(-\sin x)(\sin x) - (\cos x)(\cos x)}{\sin^2 x} = \frac{-(\sin^2 x + \cos^2 x)}{\sin^2 x} = \frac{-1}{\sin^2 x} \]

\[ \boxed{\dfrac{d}{dx}[\cot x] = -\csc^2 x} \]

📚 PART 2 · SECANT AND COSECANT

Write \(\sec x = \dfrac{1}{\cos x}\) as a quotient with \(u=1\) (so \(u'=0\)) and \(v=\cos x\):

\[ \frac{d}{dx}[\sec x] = \frac{(0)(\cos x) - (1)(-\sin x)}{\cos^2 x} = \frac{\sin x}{\cos^2 x} \]

Split \(\dfrac{\sin x}{\cos^2 x}\) into \(\dfrac{1}{\cos x}\cdot\dfrac{\sin x}{\cos x}\), which is exactly \(\sec x\cdot\tan x\):

\[ \boxed{\dfrac{d}{dx}[\sec x] = \sec x\tan x} \]

The same steps on \(\csc x = \dfrac{1}{\sin x}\) give:

\[ \frac{d}{dx}[\csc x] = \frac{(0)(\sin x) - (1)(\cos x)}{\sin^2 x} = \frac{-\cos x}{\sin^2 x} = -\frac{1}{\sin x}\cdot\frac{\cos x}{\sin x} \]

\[ \boxed{\dfrac{d}{dx}[\csc x] = -\csc x\cot x} \]

💡 DID YOU KNOW?
Notice the pattern: every "co-" function — cosine, cotangent, cosecant — has a negative derivative, while sine, tangent, and secant do not. The prefix "co-" itself is a seventeenth-century abbreviation of "complement": Edmund Gunter coined cosine around 1620 as shorthand for "sine of the complementary angle," since \(\cos x = \sin(90^\circ - x)\). The family resemblance in the names turns out to predict a family resemblance in the calculus, three centuries before anyone was differentiating anything.
⚠️ COMMON MISTAKE
The sign is the single easiest thing to drop. \(\sec x\) and \(\tan x\) both have positive derivatives built from products (\(\sec x\tan x\) and \(\sec^2 x\)), while \(\csc x\) and \(\cot x\) both carry a leading minus sign. Write the minus sign down the moment you recall the rule, before you substitute anything, so it never gets lost partway through a computation.
▶  Try it in your notebook first: differentiate \(f(x) = \sec x + \tan x\), and see if the result simplifies. Then reveal the check.
\(f'(x) = \sec x\tan x + \sec^2 x = \sec x(\tan x + \sec x)\). The derivative factors back into \(\sec x\) times the original function \(f(x) = \sec x + \tan x\), so \(f'(x) = \sec x\cdot f(x)\) — a genuinely elegant closed loop, and not an accident. You will see this exact combination again when Quarter 4 studies integration; a function whose derivative reproduces itself this cleanly is always worth a second look.
